## About me

I’m a Computer Science student at [UNIP](https://www.unip.br/) and a Systems Development technical graduate from [COTIL–Unicamp](https://www.cotil.unicamp.br/).

I’m interested in software development and currently looking for an internship where I can contribute, learn from an experienced team, and grow through collaboration.

My main projects include:

- **[Trilha Financeira](https://trilhafinanceiro.com/):** a personal and family finance SaaS built with React, Python/FastAPI, MongoDB Atlas, Docker, and a Linux VPS.
- **[SARsCamp](https://github.com/ricardotadeiromero/sars-camp_mobile):** a Flutter and Dart application developed as a team capstone project at COTIL–Unicamp. The project integrated campus services and earned second place at FACITEC.

## Featured projects

### Trilha Financeira

Personal and family finance SaaS focused on transactions, budgets, credit cards, goals, reports, authentication, access control, subscriptions, and AI-assisted features.

**Technologies:** React, Python, FastAPI, MongoDB Atlas, Docker, Linux, and REST APIs.

<a href="https://trilhafinanceiro.com/">View project →</a>

### SARsCamp

Team capstone project developed at COTIL–Unicamp in collaboration with Unicamp’s campus administration.

The Flutter and Dart application provides campus dining menus, authenticated meal-account balance queries, and lost-and-found searches. The project earned second place at FACITEC.

**Technologies:** Flutter, Dart, Dio, Provider, ChangeNotifier, and SharedPreferences.

<a href="https://github.com/ricardotadeiromero/sars-camp_mobile">View repository →</a>
